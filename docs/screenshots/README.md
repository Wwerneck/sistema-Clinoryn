# Capturas para a demonstração da Clinoryn

As imagens deste diretório devem utilizar exclusivamente os dados sintéticos criados por `python manage.py seed_demo`.

## Roteiro recomendado

1. Dashboard administrativo: indicadores e visão operacional.
2. Agenda da recepção: confirmação, check-in e fila.
3. Dashboard médico: agenda própria e dados assistenciais autorizados.
4. Área do paciente: consultas, prescrições e exames próprios.

Antes de publicar uma captura, confirme que ela não contém nomes, documentos, telefones, e-mails, exames ou qualquer dado real identificável.
